きりとりAI

「共有するタブを選ぶ」を押すと、選んだタブやウィンドウの映像がここに映ります。

Ctrl + Enter でも送れます。

思考の要約

使い方

  1. タブを選ぶ「共有するタブを選ぶ」を押して、AI に見せたいタブかウィンドウを選びます。
  2. 範囲を決める映った映像の上をドラッグします。決めた範囲は次に開いたときも残ります。
  3. 送信を押す押した瞬間の画面をその範囲で切り抜いて AI に送ります。返事はここに出ます。1 画面に入りきらないときは、「ためる」で何枚か取っておいてから送信すると、まとめて送れます。

履歴

設定

使うほうだけ入れれば動きます。キーはこのブラウザの中にだけ保存され、その AI の API 以外には送られません。

モデルの一覧

使うモデルは、画面上部の「モデル」から切り替えます。

深くするほど難しい問題に強くなりますが、時間と料金が増えます。モデルが対応していない深さを選ぶと、送信時に API がエラーを返します。

送った画像と回答を、このブラウザの中に保存します。
